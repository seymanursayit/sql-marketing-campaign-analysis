# SQL Marketing Campaign Analysis

## Overview
This project focuses on analyzing Facebook advertising campaign performance using SQL and marketing metrics.

## Key Skills
- SQL queries and data aggregation
- GROUP BY and aggregate functions
- CPC (Cost Per Click)
- CPM (Cost Per 1,000 Impressions)
- CTR (Click-Through Rate)
- ROMI (Return on Marketing Investment)

## Analysis
The SQL queries calculate campaign performance metrics by advertising date and campaign ID. A bonus query identifies the campaign with the highest ROMI among campaigns with total spending above 500,000.

## Files
- `marketing-campaign-performance.sql` — SQL queries for campaign analysis and performance metrics.

## Tools
- PostgreSQL
- SQL
